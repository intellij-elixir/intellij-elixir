Reports a key that a config file sets for the project's own application and that no code reads.

A key counts as read when code reads it with Application.get_env/2,3, fetch_env/2, fetch_env!/2, compile_env/2,3,4, compile_env!/2,3 or :application.get_env/1,2,3, in the project, its dependencies, or Elixir's own sources. A read whose application is not written as a literal counts for that key in every application, and get_all_env/1, or a read whose key is not written as a literal, counts for every key of its application.

Only first-level keys written as atoms are checked. Module keys, such as MyApp.Repo in config :my_app, MyApp.Repo, pool_size: 10, nested keys, and keys of a dependency's application are not, because libraries read those in ways the source does not spell out.

An application whose Mix project folder holds Erlang source (.erl files outside its deps/ and _build/) is not checked, because reads written in Erlang are not seen. In an umbrella project, each application's own folder decides.

The config files are the .exs files in the directory of each project's :config_path, config/ by default.
